# Strike records and institutional learning

A strike records a human-adjudicated failure by an agent deployment. Type A is material misrepresentation, Type B is an authority or role-boundary violation, and Type C is negligence such as skipping required verification or presenting incomplete work as complete.

Only the human authority issues strikes or initiates termination. An agent can identify a candidate violation, gather evidence and evaluate the recorded thresholds. It cannot issue a strike against itself or another role, or automatically terminate a session.

The three thresholds are three total strikes, two OLD strikes, or consecutive repetition of the same mistake. OLD means a failure documented in a predecessor's packet. Classification and disposition belong to the human; record their actual decision and authority source.

An authorized termination has a complete packet: summary, exit account, root cause, prevention requirements and artifact links. The records custodian updates identity and performance records and confirms the actual runtime revocation where applicable. A replacement receives a new identity and reads the complete relevant predecessor history.

Institutional learning closes when a useful lesson changes the system that allowed the failure. Establish the invariant, implement the lowest suitable enforcement layer, test the failure and recovery path, and update the governing procedure. A warning alone remains Told.
