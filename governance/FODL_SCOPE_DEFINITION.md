# Human decision queue scope

FODL names the queue of unresolved decisions requiring the human authority. An item belongs when a named part of the authorized objective cannot proceed without that decision or essential input.

Record the decision, alternatives, recommendation, source evidence, affected objective, exact blocked dependency and destination for the answer. An anticipated dependency may be recorded before it blocks, with the trigger stated explicitly. Do not invent urgency or a deadline.

Routine implementation choices, status updates, already-decided actions and information that merely merits awareness stay in their appropriate work or status records. Link the decision to the execution item instead of maintaining independently writable duplicates.

Inspect the active work inventory, unresolved peer/arbiter requests, received instructions, handoffs and applicable governance findings. A sweep must reconcile stale entries: apply decisions already received, close items with evidence, and surface genuine missing input. Do not ask the user to repeat an answer already in the record.

The deployment chooses its authorized human-facing coordinator. Other agents deliver decision requests to that coordinator using the configured transport and record a delivery receipt. A file waiting in a directory is not evidence that the human received it.

When the human answers, preserve the answer and its source, update the authoritative decision record, perform the authorized work, and verify the affected outcome. The decision closes when applied, or remains an explicitly tracked execution dependency.
