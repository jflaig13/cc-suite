# Quality and verification ladder

Choose review work for the subject and its risk. State the exit predicate before the first pass. Each selected protocol runs in full; duplicate rituals do not add evidence.

## Product and data truth

| Work | Protocol | Exit evidence |
|---|---|---|
| User workflows and consequential data | Atomic verification | Complete extraction, independent basis, comparison and derived verdict |
| Tier S/A changes at EDG-2 or above | Builder/reviewer V-Loop | Required stages and exact-subject evidence, with independent verification |
| Verification design | Verification independence | Separate implementation and authoritative input basis |

## Deliverable quality

| Rung | Use | Exit evidence |
|---|---|---|
| Q0: writing standard | Every first draft | Concrete, human, source-grounded writing |
| Q1: Asymptote | Writing, operating rules, specifications and substantive deliverables | A full named-lens cycle with no changes |
| Q2: cross-model verification | Tier S/A, EDG-2+, operating-rule changes, verification verdicts, and sensitive user-facing work | Other model family; zero critical findings in two consecutive passes on the frozen subject |
| Q2b: parallel lenses | Multiple discovery angles inside Q2 | Union of findings repaired, then two consecutive clean serial whole-subject reads; coverage debt explicit |
| Q3: Line Check | A requested human walkthrough or launch review | Binary readiness evidence for the exact subject, followed by the applicable walkthrough |

An implementation change invalidates affected evidence. Review the new frozen subject after repair. Residual taste choices belong to the human; a recurring substantive finding is not convergence. Reframe a plateau rather than relabel it clean.

Named rituals such as the seven-wave audit are used when selected or specifically requested. Model/host mechanics are deployment configuration. The platform-agnostic protocol does not prescribe a particular vendor, model ID, price or default agent count.
